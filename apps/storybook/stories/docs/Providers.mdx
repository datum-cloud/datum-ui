# App Providers

Web-only theme provider setup. For the token model, see `Foundations/Theming & Dark Mode`.

Configure ThemeProvider for light/dark/system theme switching.

## ThemeProvider

Wrap your app with `ThemeProvider` for theme management:

- **Light/dark/system** mode switching
- **System preference** detection
- **localStorage** persistence
- **CSS transition** control during theme switches

## Basic Usage

```tsx
import { ThemeProvider } from '@datum-cloud/datum-ui/theme'

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          {children}
        </ThemeProvider>
      </body>
    </html>
  )
}
```

## Theme Hook

Access and control the current theme:

```tsx
import { useTheme } from '@datum-cloud/datum-ui/theme'

function MyComponent() {
  const { theme, setTheme, resolvedTheme } = useTheme()

  return (
    <select value={theme} onChange={(e) => setTheme(e.target.value)}>
      <option value="system">System</option>
      <option value="light">Light</option>
      <option value="dark">Dark</option>
    </select>
  )
}
```
