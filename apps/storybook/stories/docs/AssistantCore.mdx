# Assistant Core

`@datum-cloud/datum-ui-assistant-core` is the platform-free core shared by the
web assistant and the React Native components. It has no React, DOM, or React
Native dependency: `fetch`, the base URL, and the token source are injected.
Its only dependency is `ai` (a peer, for the `UIMessage` types).

## Transport example

```ts
import { applyAssistantEvent, createAssistantTransport } from '@datum-cloud/datum-ui-assistant-core'

const transport = createAssistantTransport({
  baseUrl: 'https://patch.staging.env.datum.net',
  fetch,
  getToken: () => session.getAccessToken(),
  refreshToken: rejected => session.handleUnauthorized(rejected),
})

for await (const event of transport.sendStreaming({ text, contextId, projectName, signal })) {
  messages = applyAssistantEvent(messages, event)
}
```
